# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Bookify, please report it **privately** so it
can be fixed before it is publicly disclosed.

**Please do not open a public GitHub issue for security problems.**

Instead, use one of these channels:

- **GitHub Security Advisories** — [open a private advisory](https://github.com/neemchand/bookify-api/security/advisories/new)
  (preferred).
- **Email** — neemchand@thelightninggroup.co.uk

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (a proof of concept if possible)
- Affected version / commit
- Any suggested remediation

## What to expect

- We aim to acknowledge your report within a few days.
- We will keep you informed as we investigate and work on a fix.
- We will credit you in the release notes once the issue is resolved, unless you prefer to
  remain anonymous.

## Scope

Bookify is a demonstration project. Even so, we take reports seriously — especially anything
touching authentication, the booking/inventory logic, or the Kafka event handling. Thank you
for helping keep the project and its users safe.
